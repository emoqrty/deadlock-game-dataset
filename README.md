## 🌟 Interactive Live Companion & Web Tools

For real-time rank tracking, item synergizing, and meta analysis without third-party login:
- 📊 **[Deadlock Rank Distribution & Leaderboards](https://deadlocktracker.wiki/ranks/)** — Track active rank brackets, percentiles, and hidden MMR calibration.
- 🦸 **[Heroes & Hero Labs Ability Kits](https://deadlocktracker.wiki/heroes/)** — Complete talent trees, cooldown stats, and scaling for all 40+ playable and test-phase heroes (including Sinclair, Graves, Holliday, and Calico).
- 🛒 **[Interactive Item Shop & Upgrades](https://deadlocktracker.wiki/items/)** — Tier 1 through Tier 4 Spirit, Vitality, and Weapon items with real-time stat calculations.
- 📜 **[Live Patch Notes Tracker](https://deadlocktracker.wiki/patch-notes/)** — Documented hero balance changes and map adjustments.

## 📦 Dataset Schema & Contents

This repository extracts and organizes data directly from game files:
- : All 42 registered hero IDs and internal codenames.
- : Full catalog of 150+ shop items, soul costs, tier gates, and active ability cooldowns.
- : Current percentile curve across Obscurus through Eternus rank tiers.
